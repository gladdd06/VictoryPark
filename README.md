# Парк Побед — сайт-визитка

Одностраничный сайт парка в Приэльбрусье с интерактивной картой.

## Состав

- `index.html` — весь сайт в одном файле (разметка, стили, скрипт, карта в SVG).
- `.nojekyll` — служебный файл для GitHub Pages.

Сборка не нужна. Шрифты (Unbounded, Golos Text) подключаются с Google Fonts.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Source: «Deploy from a branch», ветку `main`, папку `/ (root)` и нажмите Save.
4. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как править

- Тексты первого экрана и подвала — прямо в `index.html`.
- Названия и подписи точек карты — в массиве `points` в конце файла и в кнопках с атрибутами `data-pin` / `data-pin-go`.
